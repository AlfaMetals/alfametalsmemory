ALFA METALS – MATERIAL-MEMORY

Enthalten:
- index.html: spielbares Memory (16 Karten, 8 Materialpaare)
- assets/: Kartenbilder und ALFA-Stil für die Rückseite
- qr-code-erstellen.html: QR-Code-Helfer für die spätere öffentliche Adresse

GitHub Pages kostenlos aktivieren:
1. Melde dich bei https://github.com/ an.
2. Öffne https://github.com/new und erstelle ein PUBLIC Repository namens alfa-metals-memory.
3. Entpacke dieses ZIP. Lade ALLE Dateien und den Ordner assets in das Repository hoch (Add file > Upload files).
4. Klicke Commit changes.
5. Gehe zu Settings > Pages.
6. Source: Deploy from a branch; Branch: main; Folder: /(root); Save.
7. Warte auf die veröffentlichte URL, z. B. https://DEIN-BENUTZERNAME.github.io/alfa-metals-memory/
8. Öffne qr-code-erstellen.html lokal, füge die veröffentlichte URL ein und erstelle den QR-Code.
9. Teste den QR-Code auf einem Smartphone, bevor du ihn druckst.

Hinweis: Die Materialdarstellungen und das Kartenmotiv stammen aus einer KI-Designvorlage; es sind keine dokumentarisch echten Fotos. Das Logo ist eine stilisierte Annäherung und nicht die offizielle Originaldatei.
